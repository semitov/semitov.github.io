## Circuit Task Force

Interested in electronics and PCB design? Join the Circuit Task Force and help develop our electronic system — from initial specifications and schematics to completed PCB designs.

**Open Positions**

- PCB Design Member
- PCB Design Project Lead

### PCB Design Member

**What you’ll do**

- Create hierarchical circuit schematics
- Design PCB outlines, component placement and routing
- Translate system requirements into practical circuit designs
- Coordinate specifications, interfaces and constraints with other task forces
- Improve designs through testing and feedback

**What you need to know**

- Familiarity with KiCad or similar EDA software
- Basic understanding of digital electronics
- Ability to read and understand circuit schematics
- Willingness to learn and collaborate

### PCB Design Project Lead

**What you’ll do**

- Lead PCB development from specifications to testing
- Coordinate the team and distribute design tasks
- Review schematics, component placement and routing
- Define requirements, interfaces and design constraints with other task forces
- Guide design improvements based on testing and feedback

**What you need to know**

- Strong understanding of circuit and PCB design
- Confidence with KiCad or similar EDA software
- Ability to review schematics and PCB layouts
- Good technical, organizational and communication skills
- Ability to coordinate a team and make design decisions

**What can give you an edge**

Previous circuit or PCB design experience, knowledge of hierarchical schematic design, and a GitHub portfolio or personal electronics projects will strengthen your application. Leadership or technical project-management experience is particularly valuable for the Project Lead position.

If you enjoy turning ideas into real hardware and want hands-on circuit and PCB design experience, the Circuit Task Force is for you.

## ASIC Task Force

The ASIC Task Force focuses on ASIC Physical Design — the process of transforming a digital circuit description into the physical layout used to manufacture a chip. Members will gain practical experience with the complete RTL-to-GDSII flow using open-source EDA tools and PDKs.

**Open Positions**

- ASIC Physical Design Member

### ASIC Physical Design Member

**What you’ll do**

- Work through the complete RTL-to-GDSII flow
- Perform synthesis, floorplanning and placement
- Build clock trees and route the design
- Conduct timing analysis and physical verification
- Use open-source EDA tools and Process Design Kits (PDKs)

**What you need to know**

- Genuine interest in chip design
- Willingness to learn new tools and concepts
- Ability to participate actively and work consistently

**What can give you an edge**

Basic knowledge of digital electronics, hardware description languages or Linux-based tools can help, but it is not required. Previous personal or academic projects related to digital design or microelectronics are also valuable.

If you are curious about how chips are physically designed and enjoy learning complex technologies through hands-on work, the ASIC Task Force is for you.

## CPU Task Force

The CPU Task Force designs and develops our RISC-V processor — from defining its architecture to implementing the hardware and running the complete system on an FPGA. Members work across processor design, RTL development and system-level integration.

**Open Positions**

- CPU Architecture Member
- RTL / Hardware Development Member
- System Integration Member

### CPU Architecture Member

**What you’ll do**

- Define the processor’s ISA and microarchitecture
- Design the datapath and control organization
- Define pipeline stages and hazard-handling behaviour
- Specify interfaces between hardware blocks
- Turn architectural decisions into clear implementation specifications

**What you need to know**

- Basic understanding of computer architecture
- Familiarity with digital logic and processor components
- Good analytical and problem-solving skills
- Ability to document and communicate design decisions

### RTL / Hardware Development Member

**What you’ll do**

- Implement the processor architecture in SystemVerilog
- Develop the datapath, control logic, register file and ALU
- Implement and integrate pipeline components
- Test and debug RTL modules
- Support future processor features and extensions

**What you need to know**

- Familiarity with VHDL, Verilog or SystemVerilog
- Basic understanding of digital circuits
- Understanding of combinational and sequential logic
- Willingness to learn RTL design and FPGA development

### System Integration Member

**What you’ll do**

- Integrate hardware modules into the complete processor
- Develop and maintain the top-level design
- Manage clocks, resets and module interfaces
- Implement and test the design on the target FPGA
- Diagnose integration issues and verify system operation

**What you need to know**

- Basic understanding of FPGA development
- Familiarity with hardware interfaces and RTL modules
- Understanding of clocks and resets
- Strong debugging and system-level problem-solving skills

**What can give you an edge**

Experience with RISC-V, SystemVerilog, FPGA tools or processor-related projects will strengthen your application. A GitHub portfolio, previous digital-design work or experience testing and debugging hardware systems is also valuable.

If you enjoy computer architecture, digital circuits, problem-solving and turning processor designs into working hardware, the CPU Task Force is for you.

## Software Task Force

The Software Task Force develops the low-level software required to operate and test our RISC-V system. The team works close to the hardware, dealing with embedded programming, hardware interfaces, build systems and Linux-based development environments.

**Open Positions**

- Software Developer

### Software Developer

**What you’ll do**

- Develop and debug low-level software in C
- Work with RISC-V assembly when required
- Interface software with hardware components and peripherals
- Configure build systems and cross-compilation toolchains
- Work with Linux modules, kernels and development tools
- Use Git to develop and maintain the codebase collaboratively
- Test software directly on hardware and troubleshoot issues independently

**What you need to know**

- Good C knowledge, especially pointers, memory management, type sizes, casting and the basics of `libc`
- Strong problem-solving skills and the ability to work independently
- Good knowledge of Git
- Familiarity with at least some of the following:
  - RISC-V assembly
  - Linux modules and kernel compilation
  - Cross-compilation
  - Build systems such as Make, Meson or CMake
  - Hardware components such as CPUs, GPUs, MMUs, RAM and DMA
  - Interfaces such as SPI, UART and I²C
  - Basic electronics and breadboard wiring

**What can give you an edge**

You are not expected to know everything listed above, but a solid combination of these skills will strengthen your application. Good C knowledge and the ability to investigate and solve problems independently are the essential requirements.

If you enjoy low-level programming, understanding how software interacts with hardware and solving challenging technical problems, the Software Task Force is for you.
